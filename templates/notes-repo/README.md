# My idea-scout notes (private)

This is my channel's memory for the [idea-scout](https://github.com/ZStorm-7/Video-ideation) skill. It is plain Markdown:
read it, edit it, or open it on your phone with the GitHub app. **Keep this repo private.**

| File | What |
|---|---|
| `profile.md` | who I am: niche, audience, formats, tone, what works, what flops, goals, constraints |
| `past-videos.md` | my uploads with views vs my median (repeat check + "what works here") |
| `outliers.md` | the outlier videos used for ideas, dated |
| `backlog.md` | every idea not made yet, with scores |
| `feedback.md` | how the ideas I made actually did (this is what makes the skill smarter about me) |
| `session-log.md` | one line per session |

Never put API keys here. They go in `~/.config/idea-scout/.env` or your agent's settings.
