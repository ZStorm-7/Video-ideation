# 6. Package the top picks (hooks, titles, thumbnail)

Packaging decides most of a video's result: the idea, title and thumbnail come before the video. For each top pick:

## Hooks (use `library/hooks.md`)
- **3-second hook (Shorts: the first 1.5 s):** the exact first words (short: ≤ 6 words before the first pause) + what's on
  screen on frame 1 (moving, no logo, no intro). It must restate the title's promise.
- **30-second hook (long-form):** the promise (what they'll get), the stakes (why it matters to them), the open loop (the
  question only the end answers), and one early payoff so they trust you. No "hey guys", no channel intro.
- Write 2 versions in different hook styles; recommend one.

## Titles (use `library/title-patterns.md`)
- 3 options, ≤ 60 characters, the main keyword early, a curiosity gap that the video actually pays off (no clickbait).
- Include one version built from a real autocomplete phrase (step 5b) for search.

## Thumbnail concept (use `library/thumbnail-patterns.md`)
- One focal subject + one clear emotion or object, ≤ 4 words of text that **don't repeat the title** but share its key
  word, high contrast, readable at phone size. Describe it so the creator (or an image tool) can make it.

## Shorts ↔ long-form pairing (optional but powerful)
Suggest one Short that teases each long-form pick (and links to it), or one long-form deep-dive for a Short that
outperforms.
