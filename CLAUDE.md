# Claude Code
This repo is the `idea-scout` skill. Read `SKILL.md` and follow it. To install it as a skill for every project:
`git clone https://github.com/ZStorm-7/Video-ideation ~/.claude/skills/idea-scout`, then type `/idea-scout`.
The skill repo is public and holds no personal data. The creator's memory lives in their own **private** notes repo
(default `~/idea-scout-notes`, see `python3 tools/notes.py where`); save it after each session with
`python3 tools/notes.py save "<what changed>"` (`docs/memory.md`). Never write channel data into this repo.
