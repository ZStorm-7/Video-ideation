# Hook library

The first 1.5-3 seconds decide whether a Short is watched or swiped; the first 30 seconds decide a long video's
retention. Always: start moving on frame 1, no intro, no "hey guys", say the promise immediately, restate the title.

| Style | Shape | Short example (≤ 6 words, then the rest) | Long-form 30-second shape |
|---|---|---|---|
| **Bold claim** | A surprising statement as fact | "Your password is already leaked." | claim → proof in 10 s → "here's how, and how to fix it" |
| **Question** | A question the viewer can't answer but wants to | "Why is Wi-Fi slower upstairs?" | question → why it matters to them → "by the end you'll know…" |
| **Story** | Drop into the middle of a moment with stakes | "At 3 a.m., the server caught fire." | the moment → who/where → the open question |
| **Demo first** | Show the result before explaining | (the result on screen) "This took one line." | result → "most people do it the slow way" → steps preview |
| **Contrarian** | Disagree with something the viewer believes | "Stop closing your apps." | the belief → why it's wrong → the evidence you'll show |
| **Number shock** | A concrete number that sounds wrong | "This bug cost $440 million." | number → context → the chain of events |
| **You-focused** | Put the viewer in the scene | "You've done this a thousand times." | their habit → the hidden cost → the fix |
| **Paradox** | Two true things that seem impossible together | "The fastest code is the slowest." | the paradox → a hint → the payoff promised at the end |

Rules: the hook's key word appears in the title; the thumbnail shows the hook's image; the first payoff comes by 30 s in
long-form (don't make them wait); every 5-8 s (Shorts) or 30-60 s (long) open a new small question ("but…").
