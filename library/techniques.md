# Ideation techniques

Pick the 2-3 that fit the channel. Every technique still has to borrow an outlier's psychology (step 3) and pass the
"anyone test" (could another channel post it unchanged? then it's not specific enough).

| Technique | How | Example (coding / tech channel) |
|---|---|---|
| **Audience questions** | Mine comments on the creator's and the outliers' videos for questions; each good question is a video | "Why does my code work on my laptop but not on the server?" |
| **Contrarian take** | Take a widely held belief in the niche and show where it's wrong (with proof) | "Python isn't slow. Your loop is." |
| **Myth vs reality** | A popular myth, tested | "We tested if closing apps saves battery" |
| **Comparison / versus** | Two things the audience is choosing between, judged with a clear winner | "$300 laptop vs $3,000 laptop: same code, timed" |
| **Challenge** | A constraint + stakes + a deadline | "I built an app using only a phone in 24 hours" |
| **Transformation** | Before → after with the process | "My 2 FPS game to 60 FPS in 5 fixes" |
| **Imagine you're…** | Put the viewer inside the system (second person) | "Imagine you're a password. Here's your worst day." |
| **Metaphor world** | Explain a mechanism as a place or story | "RAM is a hotel and Chrome is the worst guest" |
| **Hidden mechanism** | Something everyone uses daily, and the surprising thing inside it | "What actually happens when you press Enter in a URL bar" |
| **Stakes story** | A real event told through its consequence, present tense | "A software glitch lost this company $440 million in 45 minutes" (Knight Capital, 2012) |
| **Trend + niche** | A trending topic seen through the channel's lens | "The new AI phone feature, explained by what the chip does" |
| **Series / format** | A repeatable frame with endless episodes | "Explaining X like you're 5, then like you're a senior engineer" |
| **Ranked list with a twist** | A list where the order itself is the story | "Every sorting algorithm, ranked by how long it would take to sort the Earth" |
| **What-if twist (use sparingly)** | Only with a specific, new twist an outlier proves; generic "what if" is the most overused AI idea | "What if your PC ran at the speed of light?" only if the twist is new |
