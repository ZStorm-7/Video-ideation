# Title patterns

≤ 60 characters (never past ~70: it gets cut), main keyword early, a curiosity gap the video truly pays off. The title,
the thumbnail and the first spoken line should all share the same key word.

| Pattern | Example |
|---|---|
| I [did X] for [time/constraint] | I Coded Only on My Phone for 7 Days |
| Why [surprising fact] | Why Your Wi-Fi Is Slower Upstairs |
| The [adjective] Truth About [thing] | The Uncomfortable Truth About Free VPNs |
| [Number] [things] That [result] | 5 Settings That Doubled My Battery |
| Stop [common habit] | Stop Closing Your Apps |
| [A] vs [B]: [stakes] | $300 vs $3,000 Laptop: Same Code |
| How [person/thing] [did something unexpected] | How One Typo Crashed the Internet |
| This [thing] [does something wrong/strange] | This Bug Cost $440 Million |
| What Happens When You [everyday action] | What Happens When You Press Enter |
| You've Been [doing X] Wrong | You've Been Charging Your Phone Wrong |

Write titles before the video (packaging first). Make 3; at least one uses a real autocomplete phrase (search), one is
pure curiosity (browse/Shorts feed).
